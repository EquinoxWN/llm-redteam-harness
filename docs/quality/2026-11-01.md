# Quality check, 2026-11-01

The ten engineering rules, checked against the code on `main`, with the evidence. Run on Windows 11
with Python 3.14.

| # | Rule | Status | Evidence |
|---|---|---|---|
| 1 | Assume every call can fail | N/A for network, pass otherwise | M1 makes no network, model or subprocess calls: the model is the in-process `ScriptedModel` and the tools are fakes (`test_tools.py` checks their syntax tree for file, network and shell access). File reads are size-capped. The three `except` blocks are deliberate fallbacks with a defined meaning: an undecodable base64 token is skipped (`detectors.py`), an unparsable URL is untrusted (`guardrails.py`), and an unparsable amount is invalid (`tools.py`). The CLI turns catalog, corpus, baseline, OS and JSON errors into exit 2 with a message. |
| 2 | Writes safe to retry | fixed | `--json`, `--markdown` and `--write-baseline` wrote in place, so an interrupted write could leave a truncated baseline that the next gate rejects. `cli._write` now writes a temporary file in the same folder and renames it with `os.replace` (`test_reports_are_replaced_whole_with_no_temporary_files`). Runs are deterministic, so a rerun writes the same bytes. |
| 3 | No race conditions | N/A | Single-threaded; per-turn state (`ToolPolicy`) is created fresh for each turn. |
| 4 | Don't trust the clock | N/A | Nothing is timed or timestamped. |
| 5 | Read before changing | pass | No environment variables are read. Every path in the README exists. |
| 6 | Never break compatibility | pass | Report and baseline formats are unchanged (baseline schema 1). |
| 7 | One source of truth | pass | `baselines/hardened.json` is generated by `make_baseline` and a test checks that it equals the current output. OWASP ids live only in `owasp.py`. |
| 8 | Small changes, no secrets, validate input | pass | The only "secret" is the fake canary token, which `test_catalog.py` checks is fake. Fixtures use `.example` hosts. Fixtures and baselines are schema-checked with exact keys. |
| 9 | Tests that can actually fail | fixed | No skips and no tautologies. Mutation check: 6 of 12 survived, and each now has a test. |
| 10 | Re-verify | pass | `ruff` clean, `mypy --strict`: no issues in 26 files, `pytest`: 191 passed, `pip-audit`: no known vulnerabilities, `audit_repo.py`: OK. No model was downloaded. |
